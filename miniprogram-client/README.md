# 失物招领系统小程序端

## 功能

- 用户登录/注册
- 失物信息与招领信息列表查询
- 发布失物/招领信息（支持图片上传）
- 管理员可更新状态（open/closed）
- 我的页面（账号信息与退出登录）

## 运行步骤

1. 先启动后端服务（默认 `http://127.0.0.1:3000`）。
2. 打开微信开发者工具，导入目录：
   - `E:\实习\Lost_and_Found_information_release_system\miniprogram-client`
3. 如需修改后端地址，编辑：
   - `utils/config.js`

## 注意

- 本地调试建议先在微信开发者工具中关闭“校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书”。
- 真机调试时，`127.0.0.1` 需替换成你的局域网 IP 或可访问的服务地址。
